# Clinic Dial terminology (user-facing)

Use these names consistently in the owner workspace and visitor receptionist.

| Term | Meaning | Avoid in UI |
|------|---------|-------------|
| Clinic Dial | Product name for the owner workspace and platform | Lala |
| Rhea | Name of the AI voice receptionist | Bot, agent, Lala |
| Appointment | A scheduled visit stored in Clinic Dial | Booking (except as a verb: “Book appointment”) |
| Enquiry | A website form submission about care | Consultation, lead, ticket |
| Patient | A person with a clinic record | Customer, contact |
| Service | An approved, bookable catalogue item | Product, offering |
| Draft service | Imported suggestion not yet approved | Live service |
| Conversation | A visitor receptionist session (with consent rules) | Chat log, call recording |
| Handover | A request for a clinic team member | Escalation, ticket |
| Opening hours | Clinic-local weekly windows for public booking | Availability window, UTC minutes |
| Receptionist | The AI assistant for visitors | Bot, agent, clinician |
| Enquiry connection | Website form API key that forwards enquiries | “Website connected” (too vague) |
| Website import | Fetching public pages into knowledge/drafts | Sync, scrape |
| Calendar sync | External provider event status (when connected) | Implied success without a status |

## Voice

Calm, warm, precise. Short sentences. Active voice. Sentence case for headings and buttons. No em dashes (U+2014) in user-facing copy. En dashes in time ranges (10:00–18:00) are fine.
